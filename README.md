# 🚀 TOPAKTIE - Globales Krypto- & Aktien-Dashboard

Ein hochmodernes, responsives Finanz-Dashboard, das Echtzeit-Marktdaten ohne Schnickschnack auf den Punkt gebracht. Entwickelt als interaktive Full-Stack-Webanwendung, um Nutzern die Analyse des weltweiten Finanzmarktes zu vereinfachen.

## ✨ Hauptfunktionen

* **Unendliche Weltmarkt-Suche:** Durchkämmt live das gesamte Yahoo-Finance-Netzwerk nach Aktien und ETFs.
* **Mobiles Preis-Alarm-System:** Nutzer können einen Wunschpreis und ihre E-Mail-Adresse eintragen. Das System prüft den Kurs und sendet bei Erreichen vollautomatisch eine Benachrichtigung.
* **Integrierter ETF-Sparplan-Rechner:** Berechnet auf Basis finanzmathematischer Zinseszins-Schleifen den Vermögensaufbau für frei wählbare Laufzeiten und Sparraten.
* **Interaktive Plotly-Charts:** Visualisiert reaktive Kursverläufe für frei wählbare Zeiträume (1 Monat bis 1 Jahr) im edlen Darkmode.
* **Dynamische Währungsumrechnung:** Rechnet alle globalen Werte per Knopfdruck live von USD in EUR um.
* **Börsen-Wecker:** Erkennt automatisch anhand der Systemzeit, ob die Leitbörsen aktuell geöffnet oder geschlossen sind.

## 🛠️ Technische Details & Bibliotheken

* **Sprache:** Python 3
* **Framework:** Streamlit (für das responsive Web-UI)
* **Datenquelle:** `yfinance` (Yahoo Finance API)
* **Grafiken:** `plotly` (für interaktive Vektordiagramme)
* **Cybersecurity & Kommunikation:** `smtplib` (Verschlüsselter E-Mail-Versand via TLS)
